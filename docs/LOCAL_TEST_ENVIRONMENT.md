# 本地测试环境能力边界（Venera HM）

> 目的：把“必须上手机才能验证”的范围压到最小，并明确哪些结论本地永远给不了。
> 最后核对：2026-10-17。所有检查**不安装、不启动应用、不点手机、不访问真实站点或账号**。

## 一、当前本地能力分层

| 层次 | 手段 | 能证明什么 | 证据 |
| --- | --- | --- | --- |
| 真实 SDK 编译 | hvigor + API21 SDK | ArkTS 类型/API 误用、签名产物可生成 | `logs/*-build*.log` |
| 生产代码行为 | 在 VM 中加载**实际 `.ets` 源码**执行真实方法 | 状态机、分页、错误隔离、并发竞态、文件安全 | 46 套夹具 |
| 真实主机桥 | 实际 NAPI addon + 未修改的安装源脚本 | 源适配器在真实 JS 引擎中的行为 | `*_napi_cases.js` |
| 界面契约/路由 | 静态结构校验（本次新增） | 入口控件缺失、路由指向已删页面、三处选源脱钩 | `tools/ui_contract_cases.js` |
| 测试自身可信度 | 故障注入负向对照 | 挂起的测试不会伪装成通过；契约检查能真的失败 | `local_watchdog_cases.js`、`ui_contract_negative.js` |

## 二、新增：界面契约与路由完整性（12 项）

`tools/ui_contract_cases.js` 直接读生产源码与 `main_pages.json`，覆盖此前**只能在手机上暴露**的一类缺陷：

1. 每个注册页面都有对应文件和匹配的 `@Entry struct`。
2. 所有 `router.pushUrl/replaceUrl` 目标都已注册且文件存在——**这条能直接抓住“删了页面但别处还在跳转”**。
3. 没有任何源码还引用已删除的独立聚合页。
4. 聚合入口在源下拉框内，且不存在独立“聚合”按钮。
5. 搜索、探索、分类三者都绑定同一个 `SelectedSource`（订阅 + 发布）。
6. 源被移除/不支持搜索时**不会静默改写**共享选源。
7. 聚合会话没有人为并发上限。
8. 聚合分区用 `LazyForEach` 且只做局部更新。
9. 后台任务使用文档规定的 `LIVE_VIEW` 子模式，且没有盲停/盲重试。
10. 后台许可被拒时仍允许显式前台下载。
11. 下载控制保留代际与旧 runner 等待。
12. 有按钮的页面都接了 `onClick`，且无 TODO/FIXME 残留。

**负向对照** `tools/ui_contract_negative.js` 会构造一个“按钮跳转到未注册页面”的临时项目，
断言检查器退出 1 并报出 `unregistered pages/Ghost`。没有它，绿色结果可能只是空跑。

## 三、关于 ArkUI 本地渲染：已查清，价值有限

我实际启动了 DevEco 自带的 `Previewer.exe`（PC 上的真实 ArkUI 引擎），并逐项排除了参数问题：

- **可用**：引擎正常初始化，创建 1080×2340 渲染表面，并输出了真实渲染帧（`Get first render buffer`）。
- **`-f`** 是配置文件路径（`fontconfig.json`），不是资源目录；`-hs` 是 JS 堆（49152–524288）；`-d` 会等待调试器。
- **未打通**：页面仍走旧 JS 前端（`jsi_base_utils.cpp: Compile js bundle failed`、`no root component`），
  尽管 `ProjectModel: Stage` 已生效。它需要 DevEco IDE 通过命名管道驱动的 preview 构建变体，
  而 hvigor 的基础任务里没有 preview 任务（由 IDE 插件注入）。

**更关键的判断**：即使渲染成功，对本应用的收益也有限。Venera 的页面在 `AppInit` 阶段就依赖
关系型数据库、文件系统、网络和我们自己的 native 源引擎；预览器没有这些，页面只会停在错误态。
因此我没有继续投入逆向它的命令行，转而做了上面更可靠的静态契约层。

> 结论：**布局像素级观感、真实手势、帧率**仍然只能在设备上看；但“入口没了/跳转崩了/选源脱钩”
> 这类高频回归，现在本地就能拦住。

## 四、仍然只能实机验证的

- 系统裁决：后台连续任务是否批准、`9800005` 是否真的消失、挂起/取消回调的真实时序。
- 真实硬件：音量键消费、电量/状态栏、GPU 解码帧率、真实捏合与滚动手感。
- 真实站点与账号：站点改版、登录态、收藏/评论写操作（且用户要求不碰真实账号）。
- 跨进程：杀进程后恢复、通知点击冷启动路径。

## 五、如何运行

```powershell
# 全部本地回归（47 套 + 2 项负向对照，逐套超时/退出码/完成摘要）
.\tools\run_local_search_download_regression.ps1

# 只跑界面契约与路由完整性
node tools\ui_contract_cases.js
node tools\ui_contract_negative.js
```

每套独立进程运行，必须打印完成摘要；`WATCHDOG`、缺少最终标记、未注册路由都会判失败。
