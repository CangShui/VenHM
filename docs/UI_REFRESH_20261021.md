# UI 改造：浅灰圆角卡片与悬浮导航（仅前端、仅本地）

## 用户要求与施工边界

按用户提供的“应用设置”“本地漫画”两张参考图统一视觉：浅灰画布、白色大圆角分组、柔色图标块、清晰大标题、内缩分隔线、悬浮胶囊底栏。
**本次没有安装、启动或操作手机，也没有修改后端。** 源、网络、缓存、下载调度、数据库、模型及系统生命周期逻辑均在施工边界之外。

施工前建立[原始边界基线](<../logs/ui-refresh-20261021/baseline.json>)。
[守卫](<../tools/ui_refresh_guard.js>)确认 **99 个受保护后端/配置文件哈希一致**、所有原有非 build/Builder 方法与路由目标保留。
此外，12 个有完整原文快照的页面逐一验证字段和非渲染事件回调一致；阅读器正文/手势区域保持原样。

## 实际 UI 改动

### 统一组件

- [UiKit](<../entry/src/main/ets/components/UiKit.ets>)：浅灰 `#F4F5F8`、白卡、24vp 卡片圆角、20vp 页面边距、30vp 标题、46vp 柔色图标块、82vp 自适应设置行及本地矢量图标。
- [UiModifiers](<../entry/src/main/ets/components/UiModifiers.ets>)：主按钮、次按钮、轻量操作和危险操作四个层级。常规触达高度44vp，危险操作不再是同权重的大蓝按钮。
- 共用封面卡片统一圆角和字体，空状态增加文件夹插画和清晰说明；图片加载、缓存、PixelMap租约等方法没有改。

### 主导航与主要页面

- 首页、书架、探索、分类四个原有 Tab 身份保持；底栏重绘为悬浮胶囊，加入原有设置路由的图标入口。没有为了照抄参考图三项导航而删功能。
- 首页：继续阅读封面、标题层级、卡片间距重排；摘要漫画不再放进容易截断的固定高度嵌套网格。
- 书架：保留收藏/本地切换及全部收藏夹/批量管理功能。拥挤动作区可换行，收藏夹输入改为竖排，避免窄屏把输入框挤没；底部留足悬浮栏空间。
- 探索/分类：白色源选择控件、清晰分段标签与分组卡片，保持共享选源、加载、错误及重试行为。
- 搜索：源选择和关键词分成两行；聚合仍在同一下拉框中，历史和分源结果统一卡片/按钮。查询、筛选、分页与数据源逻辑没有改。

### 设置及其他页面

- 设置是五组白色圆角卡片：“阅读与统计”“内容与存储”“漫画源与收藏”“数据与备份”“关于与运行时”。全部9个既有路由入口保留；没有添加无后端的假设置项。
- 下载页：任务白卡、原有真实进度条、轻量状态，继续/暂停为主动作，取消/重启为中性动作，删除为弱化危险动作，按钮可换行。
- 详情/评论/收藏/追更/统计：统一页头、卡片、间距和操作层级；详情原来的复制、分享、下载、评论、章节等事件不变。
- 缓存/阅读设置/备份/源管理/账号/仓库/排行/诊断等页面沿用同一套控件排版。
- Web登录仅动工具区；图片查看器仅动工具栏；阅读器仅动顶栏、底栏和目录的三个 Builder。正文画布、缓存数量、复用、手势及尺寸回调未改，阅读区继续保留暗色。
- 登录与源脚本弹窗统一圆角、输入框和可换行操作，校验与脚本回调原样保留。
