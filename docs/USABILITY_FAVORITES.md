# 本地收藏夹：可用性验收记录

## 结论与验收口径

本轮按上游 `favorites_manager.dart` / `local_favorites_page.dart` / `favorite_actions.dart` 补齐了**收藏夹管理**，并在设备上通过了隔离回归与真实 UI 操作。这仍只是收藏模块的验收，不代表整个应用可用性通过。

分层口径与 [USABILITY_HISTORY.md](USABILITY_HISTORY.md) 一致：应用自身的导航/存储/UI/桥接缺陷必须修复，只有可复现的上游规则缺陷才可豁免。

## 修复的真实缺陷

设备与代码审查发现三个**用户可见的错误**，均非源规则问题：

1. **取消收藏残留（最严重）**：`isFavorite()` 查询任意收藏夹，但取消时只删 `folder=''` 并把标志置 false。漫画若只存在于命名收藏夹，或同时存在于多个收藏夹，界面会显示“未收藏”，实际记录仍在。
2. **空收藏夹无法存在**：`folders()` 由 `SELECT DISTINCT folder FROM favorites` 推导，新建一个还没放漫画的收藏夹立刻消失。
3. **收藏夹不可管理**：没有新建/重命名/删除/排序 UI，详情页固定写入默认夹，同一漫画无法放入多个收藏夹。

## 本轮实现

- 新增 `favorite_folders` 表（名称 + 显示顺序）并原地迁移：升级时从既有 `favorites.folder` 播种，不删表、不清空收藏。`''` 作为移植版的默认收藏夹（上游强制命名夹，此处差异已记录）。
- `FavoritesDao` 按上游语义重写：`createFolder` / `renameFolder` / `deleteFolder` / `updateFolderOrder`（对应 `folder_order`）、`add`（重复返回 false）、`moveFavorite`、`copyFavorite`、`batchMove` / `batchCopy` / `batchDelete` / `reorder`、`foldersOf`、`isFavoriteIn`。
- 名称校验对齐上游 `validateFolderName`：空、超 50 字、含双引号、重名均拒绝。
- 排序沿用上游默认 `newFavoriteAddTo='end'`（`MAX(display_order)+1`）；移动/复制插入目标夹顶部（`MIN-1`），与 Dart 的 `minValue(target) - 1` 一致。
- 书架页新增收藏夹条、新建/重命名/删除夹、前移/后移、多选（全选/取消/移动/复制/移除），删除与移除都有确认。
- 详情页“收藏”改为上游的**按收藏夹加入/移出面板**；长按等价于 `quickFavorite`（只加入默认夹，已存在则 no-op）。原先的“一键全局取消”不再是唯一入口。

设备隔离回归逐项（`离线验收 → 运行收藏夹逻辑回归`）：

```

PASS · 从单个收藏夹移除不影响其它收藏夹（修复“取消收藏残留”）

PASS · 复制保留来源并写入目标收藏夹
PASS · 收藏夹内排序按列表顺序持久化
PASS · 收藏夹顺序持久化
```

## 未覆盖 / 未实现，下一轮仍须继续

- **拖拽排序未实现**：上游用长按拖拽重排收藏夹与夹内漫画；HM 目前提供前移/后移与列表顺序 API（`updateFolderOrder` / `reorder`），交互方式不同，已在代码注释标注。
- 多选/全选/移动/复制 UI 已编译但**未做设备全流程点击**；本次设备验证集中在新建/删除夹与详情页面板。批量移动/复制的语义只由隔离回归覆盖。
- 未实现的上游收藏功能：网络收藏夹（`network_favorites_page.dart`）、收藏夹与网络收藏夹绑定（`folder_sync`）、稍后读、追更夹、`moveFavoriteAfterRead`、`readLaterFolder`/`quickFavorite` 设置项、从 JSON 导入收藏夹、封面本地缓存（`LocalFavoriteImageProvider`）、收藏同步。
- 收藏夹封面缓存与 `translated_tags` 列未移植；标签翻译整体未实现（见功能清单）。
- 大数据量（数千条）分页与滚动性能未测；书架目前一次加载一个收藏夹的全部条目。
- 未在真实用户收藏数据上执行删除/移动；后续应在独立测试设备或备份后验收。

```powershell
# 设备：Venera HM → 收藏（书架）
# 1. 新建收藏夹 → 输入名称 → 创建；强制停止并重进，确认空收藏夹仍在。
# 2. 选中该夹 → 删除夹 → 确认，确认仅剩默认收藏夹。

# 设备：Venera HM → 历史 → 离线验收
# 3. 运行收藏夹逻辑回归，应出现 10 条 PASS。
# 4. 打开本地样本详情 → 收藏 → 面板内 加入/移出，检查头部与行内状态。
# 5. 结束后用「清理本页生成的样本」移除样本。
```
