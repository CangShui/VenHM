# 图标尺寸与经典沉浸阅读修正（仅本地）

本轮按用户新反馈修正两项前端体验：全局图标大小，以及“正文全屏、仅下方浮层、点图收起、正中唤出”。
**未安装、未启动、未操作实体机。** 源、网络、下载队列、缓存实现、数据库、模型和56个非UI阅读方法保持不变。

## 1. 全局图标：固定方框、原生资源渲染

[UiIcon](<../entry/src/main/ets/components/UiKit.ets>)不再使用运行时Shape/Path/viewPort组合。
改为24个打包SVG资源（明确24×24、viewBox0 0 24 24）+原生Image/Contain。
内层图片和外层容器使用相同尺寸与min/max约束，并关闭flex扩张/压缩，触摸区域仍由外面的44/46vp按钮/图标底块提供。

[纯尺寸/着色工具](<../entry/src/main/ets/components/UiIconMetrics.ets>)：无效/非正尺寸回落24，正尺寸限制16..72；现有16/17/19/21/22/23/24/30/68均保留。
不自行乘以字体缩放或设备密度。使用SDK支持的20数值ColorFilter矩阵对白色描边资源着色并保留alpha，避免用fillColor把空心图形填实。
现有name/color/iconSize接口、图标调用位置、主题与设置行等兄弟组件不变；桌面启动图标也没动。

本地证据：[16项图标回归](<../tools/ui_icon_size_cases.js>)执行真实尺寸/着色方法，检查24个资源XML与精确矢量边界、26个实际调用点、原生Image固定尺寸及反例。
旧cloud路径确有少量描边越界，新SVG已内缩修正；这不是对用户整体现象的“已实机定位”宣称。

## 2. 阅读器：一个全屏画布，一个下方弹出浮层

[ReaderPage](<../entry/src/main/ets/pages/ReaderPage.ets>)现遵守：

1. 新进入正文时下方浮层可见；没有顶部常驻工具横幅。
2. 浮层显示时，点任意已就绪漫画图片先收起浮层，**同一次点击绝不翻页**。
3. 隐藏后，点击可见阅读窗口正中区域唤出；长图采用窗口坐标而不是整张长图高度；考虑画布屏幕偏移。
4. 左右边缘在浮层隐藏时继续遵守原有方向、反转和区域设置。缩放时不误翻页，但仍可单击中部唤出菜单。
5. 双击缩放、捏合、拖动、过期手势、页面不可见、加载与布局变动仍有门禁。
6. 同屏慢图不阻止对已加载图片收起/唤出菜单，但真正翻页仍要求完整可见图片组就绪。
7. 自动滚动时可以用正中单击停止自动阅读并唤出菜单，避免隐藏UI后找不到停止入口。
8. 目录外点击可收起浮层，返回键先关闭目录/菜单，再交给原返回流程。

原来的返回、详情、章节/页切换、目录、自动阅读、模式、亮度、设置、图片收藏/菜单、统计都保留在下方浮层中。
浮层短时从下方滑入，操作可换行、短屏可滚动；不再有常驻“显示工具栏”按钮。

**正文与浮层是Stack兄弟节点**，工具显隐不占正文高度，不改变数据源/缓存key/renderGeneration/zoomReset，因而不会仅因开关菜单而重新排版或重载图片。
中心“不操作”的旧设置UI替换成新的经典交互说明；已有偏好数据仍保留，没有改存储层。

## 3. 阅读器窗口所有权与恢复

[ReaderWindowChrome](<../entry/src/main/ets/components/ReaderWindowChrome.ets>)是阅读器实例拥有的前端窗口控制器。
进入前保存原布局/系统栏快照，明确调用setWindowLayoutFullScreen(true)与setWindowSystemBarEnable([])；隐藏、退出或打开其他页面时恢复。
操作串行并有代际保护，晚到的getLastWindow或setter不能在阅读器离开后继续隐藏其他页面系统栏。
部分失败会回滚；恢复失败保留原窗口快照，下一次显式操作先重试恢复，不丢弃所有权。

**API限制如实保留：**SDK没有“读取已启用系统栏名称”的精确getter。
因此快照依据isFullScreen以及系统/导航指示条避让区推断；非全屏却全部几何为零时按本应用普通页面的双系统栏基线回退。
这不是任意厂商/瞬态系统栏状态完全精确的保证。系统真实行为仍待用户以后实机确认。
